## 1. 环境定位

Notebook 只用于最初验证 BW1000/Triton 可行性，并提供 DTK 2604 的 `aillvm` 与
`libmsgpackc.so.2` 运行组件。正式实验使用独立 Conda、宿主机 DTK Module 和共享运行时。

```text
Notebook 镜像：dtk2604-base-image:v3-jupyter
Slurm 环境：Conda + compiler/dtk/26.04 + 共享 aillvm/libmsgpackc
```

## 5. Slurm 配置

```bash
module purge
module load compiler/dtk/26.04
export ENV_PREFIX=/public/home/cnic_lsb/conda-envs/rsf-triton-v2
export PATH="$ENV_PREFIX/bin:$PATH"
export LD_LIBRARY_PATH=/public/home/cnic_lsb/rsf-triton-runtime/lib:$LD_LIBRARY_PATH
export ROCM_PATH=/public/home/cnic_lsb/dtk2604-runtime-root
```

运行前检查：

```bash
python -c 'import torch,triton; print(torch.__version__, torch.version.hip, triton.__version__, torch.cuda.is_available(), torch.cuda.device_count())'
```
