## 三、陈述类型到证据的推荐映射

| 陈述类型 | 首选外部引用 | 必须同时具备的本地证据 |
|---|---|---|
| Triton 降低低层 GPU kernel 编程负担 | [1]，可辅以 [2] | 无；若谈本项目开发成本则需要工时记录 |
| Triton 对 HPC kernel 的效果与结构有关 | [2]-[4]、[11] | 本项目 stencil/SpMV/reduction/RSF 原始数据和统一计时协议 |
| 本文不计算严格性能可移植性指标 | [6] | 两平台软硬件栈清单和基准可比性说明 |
| Roofline/PMC 只提供瓶颈证据而非单因果证明 | [5] | ceiling 测量方法、计数器定义、消融实验和失败证据 |
| SpMV 的映射应结合行长分布和访问结构 | [11]-[12] | 七矩阵 metadata、固定 nnz/局部性/mapping sweep 与原始日志 |
| SeisSol 已有 GPU fusion 和多后端工程基础 | [13]-[14]、[18]-[21] | 目标 checkout 源码 inventory、构建日志和 commit |
| RSF 是状态相关且数值求解复杂 | [15]-[17] | 本文 FP64 reference、边界/非线性迭代 correctness 证据 |
| 独立 kernel 成功不等于生产应用替换 | [4]、[13] 可作背景 | pointer/stream/layout/ABI 门禁、C2-C6 日志、完整应用仍 pending 的状态记录 |
| BW1000/东方上的任何性能倍率 | 外部文献不承担该证明 | 对应平台原始日志、device-event timing、warmup/repeat、版本和失败记录 |

## 四、使用时的硬性约束

1. [3] 和 [4] 在投稿版本中必须明确标为 arXiv 预印本，不得写成已同行评议结论。
2. [15] 全文统一采用 2026 卷期年，并可在书目信息审计中保留“2025 online”的说明，避免同一文献出现两个年份。
3. [16] 的书目信息以 Oxford Academic Version of Record 为准；本地 `reference/05_...pdf` 是早期投稿稿，不能作为 GJI 卷期和页码依据。
4. [18]-[22] 的网页结论必须受版本边界限制。实验行为优先引用本项目环境快照、`versions.lock`、源代码 commit 和原始日志。
5. [24]-[30] 只证明输入矩阵身份和元数据。所有 Triton/HIP 倍率、排序和机制解释必须回到本项目实验记录。
6. 不使用“首次”“唯一”“填补空白”等绝对新颖性措辞。允许的表述是：截至 2026-10-16，在本轮限定检索范围内，尚未发现同时覆盖“双国产/非 NVIDIA DCU、同源 Triton/HIP、多类 FP64 科学 kernel、结构干预、Aging-RSF 与分级应用门禁”的公开工作。
